# Multi-factor Authentication Flask App

## Requirements

- Python 3.7+
- Flask
- Werkzeug

## Setup


## Run


Open browser: http://127.0.0.1:5000

---

# Features

- Registration with username, password, security question and symbol.
- Login with password.
- Email-less OTP (6-digit) with 30s expiry and timer.
- Security question verification.
- Symbol verification.
- Dashboard after successful authentication.

---

# Notes

- For production, configure email/SMS for OTP.
- Change secret key for Flask app.
